# Beat Master

英語を「ビート（強い単語）」と「接着剤（弱く速く読む機能語40個）」で聞き取り・話す練習アプリ。`index.html` 1ファイルで動きます（ブラウザで開くだけ）。

- 4つの型：2〜5ビート × 各25文 ＝ 100文
- 各文3ステップ：①リスニングテスト（ビートを当てる）②手拍子特訓（ビートだけ／全文・速度3段階）③スピーキングテスト（音声認識でビート判定）
- 接着剤40個の音のライブラリ ＋ 崩れ方（gonna, wanna など）
- ランダム出題、学習進捗（端末のブラウザに保存）

音声認識は Chrome / Safari の Web Speech API を使用。マイクが使えない環境では「できた」で自己判定。

公開ページ: https://tatsuya0726.github.io/beat-master/
